# KnN Yoga Academy

A lightweight one-page website for KnN Yoga Academy at Kanana Village, Ungasan, Bali.

## Preview locally

Open `index.html` directly, or run a small local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

The site has no build step or external dependencies and is ready for GitHub Pages. All booking links are controlled by `BOOKING_URL` near the top of `script.js`.
